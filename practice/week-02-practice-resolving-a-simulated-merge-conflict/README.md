# Practice Resolving a Simulated Merge Conflict

## Task Brief
Create and resolve a merge conflict locally to understand conflict markers, resolution strategies, and clean merge workflows.

## Scenario
Your team member edited the same file on a different branch. Simulate and resolve this conflict to learn real-world merge handling.

## Deliverables
- Resolved merge with clean history
- Documentation of conflict resolution steps

## Success Criteria
- Conflict markers are removed correctly
- Resolved file is syntactically valid
