# Practice Clean Commits Across Multiple Branches

## Task Brief
Create feature branches with clean, atomic commits and meaningful messages demonstrating professional commit discipline.

## Scenario
Your team lead reviews your portfolio repo and asks you to demonstrate clean commit practices across feature branches.

## Deliverables
- Feature branch with 3+ atomic commits
- Meaningful commit messages
- Clean commit history in repo

## Success Criteria
- Each commit addresses one logical change
- Commit messages follow conventional format
- History is readable without merge commits
