# Submit First Pull Request to Portfolio Repo

## Task Brief
Create a feature branch, make a meaningful code change, and submit your first pull request with clear commit messages and PR description.

## Scenario
Your team lead asks you to demonstrate clean PR workflow by adding documentation to the portfolio repository.

## Deliverables
- Pull request with clear description
- Meaningful commit message
- PR merged into main branch

## Success Criteria
- PR includes descriptive title and body
- Commit message explains the change
- PR is successfully merged
