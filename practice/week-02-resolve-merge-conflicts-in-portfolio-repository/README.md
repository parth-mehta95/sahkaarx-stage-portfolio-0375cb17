# Resolve Merge Conflicts in Portfolio Repository

## Task Brief
Create intentional merge conflicts across branches, resolve them using Git tools, and document the resolution process in your portfolio.

## Scenario
Your team needs to demonstrate conflict resolution mastery by creating and resolving real merge conflicts in the portfolio repo.

## Deliverables
- Resolved merge conflict with clear commit history
- Conflict resolution documentation in repo

## Success Criteria
- Conflicts resolved without losing code
- Documentation explains resolution strategy
- Branches successfully merged to main
