# Submit First Pull Request to Portfolio Repo

## Task Brief
Create a feature branch, make a meaningful code change, and submit your first pull request with clear commit messages and PR description.

## Scenario
Your team lead asks you to add a Python script demonstrating variables to the portfolio repo and submit it via pull request for review.

## Deliverables
- Feature branch with clean commits
- Pull request with description and code sample

## Success Criteria
- PR links to main branch
- Commit messages are clear and descriptive
