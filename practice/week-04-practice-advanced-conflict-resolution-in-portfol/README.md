# Practice Advanced Conflict Resolution in Portfolio

## Task Brief
Create intentional merge conflicts across branches, resolve them using Git tools, and document the resolution process in your portfolio.

## Scenario
Your team member modified the same file on a different branch. Create conflicting branches, trigger a merge conflict, and resolve it cleanly.

## Deliverables
- Resolved merge with conflict markers removed
- Conflict resolution documentation in README

## Success Criteria
- Merge conflict successfully resolved
- Documentation explains conflict markers and resolution strategy used
