## Task Brief
Create a comprehensive guide documenting your portfolio repository setup process and reference all basic Git commands used.

## Scenario
Your team lead requests a setup guide and Git commands reference for new developers joining the project.

## Deliverables

- GIT_COMMANDS.md with command reference

## Success Criteria
- Setup guide covers repo creation and configuration
- Commands reference includes status, add, commit, log
- Examples show real usage from your portfolio
