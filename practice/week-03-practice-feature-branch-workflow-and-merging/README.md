# Practice Feature Branch Workflow and Merging

## Task Brief
Create and merge feature branches demonstrating proper branching discipline, clean history, and integration into main.

## Scenario
Your team needs you to demonstrate feature branch workflow by creating, developing, and merging a feature branch into main.

## Deliverables
- Feature branch created and merged
- Merge commit in main branch
- Branch naming follows conventions

## Success Criteria
- Branch name is descriptive and follows convention
- Feature is complete before merge
- Main branch history reflects merge
