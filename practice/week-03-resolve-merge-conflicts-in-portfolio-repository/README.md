# Resolve Merge Conflicts in Portfolio Repository

## Task Brief
Create intentional merge conflicts across branches, resolve them using Git tools, and document the resolution process in your portfolio.

## Scenario
Your team member modified the same file. Create conflicting branches, trigger a merge conflict, and resolve it cleanly.

## Deliverables
- Resolved merge with conflict markers removed
- Documentation of resolution steps in README

## Success Criteria
- Merge completes without errors
- Conflict markers properly resolved
